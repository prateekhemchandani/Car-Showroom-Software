#  Showroom Management System

A **full-stack web application** built with **Spring Boot (Java)** and **React** for managing showrooms, employees, and cars.  
This project demonstrates a clean architecture with REST APIs and a modern frontend dashboard.

---

##  Features
- Manage **showrooms** (name, address, etc.)
- View **employees** by showroom
- View **cars** by showroom
- Interactive **React dashboard** with cards & dark theme
- REST API powered by **Spring Boot & MySQL**
- CORS enabled for frontend-backend integration

---

## 🛠️ Tech Stack
**Backend (Java + Spring Boot)**
- Spring Boot 3
- Spring Data JPA
- Hibernate
- MySQL
- Maven

**Frontend (React)**
- React + Vite
- Axios (API calls)
